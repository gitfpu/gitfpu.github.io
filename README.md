## 🛠️ 第一部分：常用终端与网络命令
当老系统遇到兼容性问题时，在终端（Terminal）中输入以下命令可以强制绕过限制。

* **Chromium 禁用沙盒启动命令**：
  ```bash
  /Applications/Chromium.app/Contents/MacOS/Chromium --no-sandbox
  ```
* **强制清除浏览器缓存刷新**：
  在 Mac 键盘上同时按下快捷键：`Command (⌘) + Shift + R`
